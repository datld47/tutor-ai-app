✅ Các bước tạo version tag trong Git và đẩy lên GitHub
1. Đảm bảo bạn đang ở đúng nhánh
git checkout main_v1C

2. Kéo các thay đổi mới nhất từ GitHub (đảm bảo đồng bộ)
git pull origin main_v1C

3. Tạo một tag với tên phiên bản
Bạn nên dùng quy ước version, ví dụ v1.0.0, v1C-release, v.v.
git tag v1C.0.4 -m "vừa mới sửa xong JSON 23H56_26/7/2025"
v1C.0.0 là tên tag (bạn có thể đặt theo ý muốn)
-m là mô tả ngắn cho tag

4. Đẩy tag lên GitHub
git push origin v1C.0.4
✅ (Tuỳ chọn) Đẩy tất cả tag lên GitHub
git push origin --tags

✅ Sau này muốn quay lại phiên bản này?
Dễ dàng dùng lệnh sau:
git checkout v1C.0.1

Lưu ý: bạn sẽ ở trạng thái "detached HEAD" – bạn có thể tạo nhánh mới từ đó nếu muốn tiếp tục phát triển từ tag này.

git checkout -b hotfix-from-v1C
Nếu bạn cần tạo annotated tag (dùng khi release chính thức, có chữ ký...), bạn có thể làm:
git tag -a v1C.0.1 -m "Annotated tag cho phiên bản ổn định"

📌 Kết luận
Tag giúp bạn lưu lại một mốc trạng thái ổn định.

Đẩy tag lên GitHub để không bị mất.

Có thể quay lại hoặc tạo nhánh mới từ tag bất kỳ lúc nào.

Nếu bạn cần tôi viết README hướng dẫn nhóm sử dụng version tag hay release, tôi có thể giúp luôn.
